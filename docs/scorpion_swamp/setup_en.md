# Scorpion Swamp Randomizer Setup Guide

## Required Software

- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
- [The Scorpion Swamp apworld]()
- [The Scorpion Swamp companion app]()
- (OPTIONAL) [The Universal Tracker apworld](https://github.com/FarisTheAncient/Archipelago/releases?q=Tracker)

## How to play

1. Install the Scorpion Swamp apworld if you haven't already by double-clicking it or manually placing it in the 
"custom_worlds/" subdirectory of your Archipelago directory. If you want to use the Universal Tracker, install it the
same way and it will automatically add itself to the Scorpion Swamp client.
2. Place your .yaml file in the "Players/" subdirectory of your Archipelago directory and generate or, if someone else
is generating the multiworld, send them your .yaml file and make sure they also install the apworld. Once generation is
complete, host the multiworld as you would any other. Generic Archipelago setup guides can be found
[here](https://archipelago.gg/tutorial/) if any of these instructions are unfamiliar to you.
3. Run the Scorpion Swamp Client in the Archipelago Launcher and connect it to your slot in the multiworld.
4. Open the Scorpion Swamp companion app and start the game. Choose to connect to Archipelago when prompted. If the
game just starts without prompting you, restart the game and ensure that "Ask to connect to Archipelago" is on in the
Preferences menu.
5. Play the game. The companion app will indicate which reference to read and will list options by the reference that
they lead to. Text uniquely added for playing in Archipelago will appear as well, typically to let you know what item(s)
you have found in a location but may also include any randomizer-specific overrides necessary for the given text. Dice
rolling, inventory management, and stat tracking are handled by the companion app along with all communications with
Archipelago.
