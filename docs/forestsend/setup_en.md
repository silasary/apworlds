# The Forest's End Randomizer Setup Guide

## Required Software

- [The Forest's End](https://sephazon.itch.io/the-forests-end) (Windows download)
- [APTFE](https://github.com/MarioManTAW/APTFE/releases)

## Installation Guide

- Download and extract the Windows version of The Forest's End.
- Download the latest version of APTFE (APTFE-X.X.X.zip) and extract to the same folder as the game.
- If the previous step was done properly, The Forest's End.exe and winhttp.dll will be in the same folder.
- Run the game.
  - On Windows: Double click The Forest's End.exe
  - On Linux:
    - Add The Forest's End.exe to Steam as a non-Steam game.
    - In Steam, go to the game's Properties->Compatibility and check "Force the use of a specific Steam Play
    compatibility tool", then select your preferred version of Proton from the dropdown.
    - Launch the game, then exit.
    - Follow [this guide](https://docs.bepinex.dev/articles/advanced/proton_wine.html) to allow mods to run.
    (Note: I recommend the Flatpak version of protontricks as at least APT has an outdated version that does not work.)
    - Launch the game through Steam.
- If all this was done correctly, you should see a place to input AP connection info on the top left.
- Use this to connect to the Archipelago server, then select "start game" from the game's main menu.

## Troubleshooting

### I seem to be stuck. How do I get back to where I came from?

Pause the game, return to the main menu, and "start game" again. You will be returned to the starting room with all progress maintained.
