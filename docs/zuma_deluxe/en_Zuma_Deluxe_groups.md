# Zuma Deluxe Groups List

This Document will list each group available.
And will show how they are typed so it will be easier to remember.

All groups are fully typed in UPPER CASE.

## Items Groups

Items Groups are separate by classification when they don't belong to any level, so Sun Idols, fillers and traps belong to this group and will be on one of this Groups depending on ther classification:
- PROGRESSIVE ITEM
- USEFUL ITEM
- TRAP ITEM
- FILLER ITEM

Also useful traps and filler all belong to this Group:
- EXTRA ITEM

Both progressive and extra live belong to this Group:
- LIVE ITEM

Now Items that have direct connection to a level belong to some groups.
Depending on what mode the level belongs:
- GAUNTLET ITEM
- ADVENTURE ITEM

If is an unlock level item they will belong to the Group:
- UNLOCK ITEM

If the item will allow you to get more points they belong to the Group:
- POINTS ITEM

This last two groups can be interpolated with the modes group making the Groups:
- GAUNTLET POINTS ITEM
- GAUNTLET UNLOCK ITEM 
- ADVENTURE UNLOCK ITEM 
- ADVENTURE POINTS ITEM

Each type of POINTS ITEM also belong to his own group:
- COIN POINTS ITEM
- GAP POINTS ITEM
- COMBO POINTS ITEM
- CHAIN POINTS ITEM

Lastly every Board in Gauntlet mode has its own group for all the related items:
- SPIRAL OF DOOM ITEM
- OSPREY TALON ITEM
- RIVERBED MOSAIC ITEM
- BREATH OF ETHECATL ITEM
- DARK VORTEX ITEM
- SWITCHBACK ITEM
- LONG RANGE ITEM
- WHEN SPIRALS ATTACK ITEM
- MUD SLIDE ITEM
- RORSCHACH ITEM
- MOUTH OF CENTEOTL ITEM
- SNAKE PIT ITEM
- SAND GARDEN ITEM
- LAIR OF THE MUD SNAKE ITEM
- LAN DING PAD ITEM
- ALTAR OF TLALOC ITEM
- CODE OF MIXTEC ITEM
- SHRINE OF QUETZALCOATL ITEM
- MIRROR SERPENT ITEM
- SUN STONE ITEM
- ZUMAIC EXODUS ITEM
- SPACE ITEM

And every Stage in Adventure mode has its own group for all the related items:
- TEMPLE OF ZUKULKAN 1 ITEM
- TEMPLE OF ZUKULKAN 2 ITEM
- TEMPLE OF ZUKULKAN 3 ITEM
- QUETZAL QUATL 1 ITEM
- QUETZAL QUATL 2 ITEM

- POPO POYOLLI 2 ITEM

## Locations Groups

The rules for locations are pretty similar to the items, specially since all locations are connected to a specific section or level.


Each Section type of location is group with his own no matter the board or stage:
- FULL CLEAR LOCATION
- LEVEL CLEAR LOCATION
- COINS LOCATION
- CHAINS LOCATION
- COMBO MAX LOCATION
- COMBOS LOCATION
- GAPS LOCATION
- ACE TIME LOCATION



Locations in each section can be separate in two big groups depending on being a type of shot or about beating a level (Ace time locations are consider skill too):
- CLEAR LOCATION 
- SKILL LOCATION

They can also be paired in group if they can be done in all the section or limited by the level in it:
- SECTION LOCATION
- LEVEL LOCATION

Depending on the mode we have two groups:
- GAUNTLET LOCATION
- ADVENTURE LOCATION

Locations in Gauntlet mode get group by difficulty:
- RABBIT LEVEL LOCATION
