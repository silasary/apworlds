# Super Meat Boy 3D

World 1 light levels start accessible. Worlds 2–5 light levels need their World Access item plus each level's access item. Bosses require ten light clears in their world.

The base seed has 75 light clears and five bosses (80 checks). Bandagesanity adds 75 bandages. Darksanity adds 75 dark clears and 75 dark-level access items, which also require the matching World Access outside World 1. Speedsanity adds 75 light A+ checks and, with Darksanity, 75 dark A+ checks. A+ checks use the same level/world access rules as their clear checks.

The default all_bosses goal requires all five bosses. The beat_the_game goal uses the World 5 route: World 5 Access, any ten World 5 light unlocks/clears, Dr. Fetus, escape and credits. Dark levels and bandages are not goal prerequisites.

Tofu Trap filler weight replaces 0–100 percent of the remaining filler slots, rounded to a whole item. The number of filler slots changes with your selected sanity options. All 139 progression items are present with Darksanity; without it there are 64.
