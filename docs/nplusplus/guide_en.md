# N++ Setup Guide

## Required Software
- The latest version of N++
- NAP++ Client

## Installation Procedures (Windows/Linux)

1. Install the latest version of N++ on PC
2. Launch the game, and with the game open, open the NAP++ Client. 

## Joining a MultiWorld Game

1. In the NAP++ Client, select "Archipelago"
2. Type in your connection information
3. Click connect
