# <ins>Bugs</ins>
You may not be able to reach certain characters in the character select menu, if so, use random. **However**, if you
use random when:
- Only have 1 character
- Are on that character

It **will** crash. In this case, only use random on the Mii Character

In certain circumstances, you may find that some characters on the roster overlap with another character. In this case,
please run /roster_fix in the client and let it do its thing. Make sure your dolphin & game path are set in your host.yaml
file or else it won't work!
