# Dorfromantik

Dorfromantik is a peaceful tile-laying game about building a landscape from a
limited stack of hexagonal tiles. This randomizer turns that stack into your
inventory: the vanilla ways of earning tiles mid-run are disabled, so a run lasts
exactly as many placements as Archipelago has given you, and the terrain you are
allowed to build with - and therefore the flags you can be offered - is unlocked
piece by piece.
