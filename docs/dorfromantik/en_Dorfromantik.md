# Dorfromantik

## Where is the options page?

The [player options page](../player-options) has all the options you need to configure and export a config file.

## What does randomization do to this game?

Normally, Dorfromantik gives you a stack of 40 tiles and lets you earn more by placing
tiles perfectly and by completing quests. In Archipelago, both of those are turned off.

Your tile stack is your Archipelago inventory. A run lasts exactly as many placements as
you have been given tiles, and when the stack runs out the run ends and you start another.
Progress is kept between runs, so a bad run costs you nothing but time.

You also start with only one type of terrain. Until you receive more, the game will only
generate tiles containing terrain you own, and — because Dorfromantik picks quest tiles to
match the landscape — flags for terrain you do not own will not appear at all.

## What items and locations get shuffled?

Items:

- **Terrain tiles** (Forest, Field, Village, Water, Train Track). Each grants both more
  tiles and a heavier presence of that terrain in the mix.
- **Quest Tiles**, each adding one guaranteed flag tile to every run.
- **Tile Packs**, generic tiles with no terrain preference.
- The game's **tile and biome unlocks**, such as the windmill, the boat, and the Sakura
  biome. Cosmetic skins are not shuffled.

Locations:

- Completing flags, counted across all your runs.
- Completing flags of a specific terrain.
- Reaching score milestones within a single run.

## What is the goal?

Whichever you choose: reach a target score in one run, or complete a target number of
flags in one run. Both ask your last run to be your best one.

How much you are given to get there depends on the Skill setting — a higher one means a
shorter deck for the same goal, so every tile has to pull more weight.

## Which items can be in another player's world?

Any of them.
