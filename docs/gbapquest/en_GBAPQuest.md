# GBAPQuest

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export a
config file.

## What is GBAPQuest?

APQuest is an original game made entirely by NewSoupVi. 

This is a Port for the Game Boy Advance based on it.

## Why does GBAPQuest exist?

Unlike the original, this has no reason to be other than to be a cool project. However after some time, I intend to polish this into an actual proper way for people to learn to do implementations for ROM games, as in Patching, using Bizhawk Client, etc. it is however, not up to the task as of yet.

## Once I'm inside the game, how do I actually play GBAPQuest?

- D-PAD: Movement
- B-BUTTON: Interact
- A-BUTTON: Shoot Confetti Cannon
- SELECT: Save
- SELECT+D-PAD-LEFT: Load Save and Reload
- SELECT+D-PAD-RIGHT: Delete Save and Reload

### Debug Toggles

These Will Make you Restart the Whole Game to it's initial Values, however with the Archipelago patch implementation it Should not let you Change anything... Hopefully.

- START: Toggle Hammer Mode
- START+D-PAD-DOWN: Toggle HardMode
- START+D-PAD-RIGHT: Toggle Extra Chest


Open chests, slash bushes, open doors, press buttons, defeat enemies.  
Once you beat the dragon in the top right room, you win. 
That's all there is! Have fun!
