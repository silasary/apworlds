# Setup Guide for TimeSplitters 2 Archipelago

## Requirements

* [Archipelago](https://archipelago.gg/tutorial/) 0.6.0 or newer (tested on 0.6.3)
* The TimeSplitters 2 `.apworld`
* [Dolphin Emulator](https://dolphin-emu.org/)
* TimeSplitters 2 for GameCube, North American version (game ID `GTSE4F`). You must provide your
  own copy.
* Optional: [Universal Tracker](https://github.com/FarisTheAncient/Archipelago/releases?q=Tracker).

## Installing

1. Double-click the `.apworld` (or copy it into Archipelago's `custom_worlds` folder) and restart
   the Archipelago Launcher.
2. In Dolphin, turn cheat codes off: Config > General > Enable Cheats. With them on, the client
   cannot lock missions (the client log says so).

## Playing

1. Start Dolphin and the game, and open "TimeSplitters 2 Client" from the Archipelago Launcher.
   The client says "Dolphin connected successfully."
2. Enter the server address at the top of the client, then your slot name at the bottom.
3. Create a NEW profile in the game and use it for this seed only.
4. Keep the client open and connected to Dolphin while you play.

## Important notes

* **One profile per seed.** The client reads trophies and story completions from the profile you
  load and sends them all as checks. A profile that has already beaten 2401 Space Station finishes
  a Space Station goal at once.
* **Do not play that profile without the client.** The game's normal unlocks come back after a
  restart without the client, so the profile would gain things you have not received.
* **Connect the client to the server before opening Arcade Custom.** Until it knows which
  characters you own, the game can crash there.
* **Story objectives are only seen while the client is running.** One completed with the client
  closed has to be done again. Trophies and level completions are read from the save and are
  never missed.
* A mission you have just received shows up the next time you open the menu it is in.
