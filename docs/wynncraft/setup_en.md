# APQuest Randomizer Setup Guide

## Requirements

- A premium (paid) [Minecraft](https://www.minecraft.net/en-us/about-minecraft) account
- The ability to run Minecraft **Java** edition
- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
- [The Wynncraft APWorld](https://github.com/EpicPuppy613/Wynncraft-APWorld/releases)

## Installation Methods

This Archipelago is designed to work with [Wynnpelago](https://modrinth.com/mod/wynnpelago), a mod for Minecraft.
For convenience, there is a "one-click" modpack to get started quickly, and it also comes with some additional quality of life features.
