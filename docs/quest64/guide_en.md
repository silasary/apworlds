# Quest 64 Recompiled Setup Guide

1. Put `quest64.apworld` in `Archipelago/custom_worlds`.
2. Put your filled-in `Quest64Recompiled.yaml` in `Archipelago/Players`.
3. Generate and host as usual.
4. In Quest 64 Recompiled, open the config menu, turn on the Archipelago
   Connector and enter the server address, your slot name and the password
   if the room has one.
