# Yooka-Replaylee Randomizer Setup Guide

## Installing the APWorld

Install the generated `.apworld` through the Archipelago Launcher.

## Generating a seed

Select `Yooka-Replaylee` as the game in your Archipelago YAML and run the normal Archipelago generator.

This APWorld currently has no custom player options.

## Client status

This package currently contains the generation-side APWorld only. A Yooka-Replaylee game client/connector is not included yet.
