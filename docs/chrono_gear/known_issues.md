# Known Issues
* Any cutscenes that immediately send you into another level or to a specific hub will do so even if you don't have
  that level unlocked. Checks in those levels are out of logic, meaning the randomization doesn't expect you to be
  able to get them yet, but it's not an issue if you do. You can Exit Stage from the pause menu to get out of the stage.
  * For the transition from Defending the Sanctum into Solitude specifically, it traps you a bit more thoroughly.
    You either need to fully close the game and reconnect, or complete Solitude and leave through the Bunker.
    This is untested, but if you have the Bunker unlocked, you might be able to Exit Stage normally in Solitude

* Rarely, a hub cutscene can interrupt the results screen for a level, which prevents the level completion unlock
  checks from being sent. You might be able to get the results screen by entering the world map and returning without
  selecting a level, but otherwise you can do the level again or have the server host release the check.

* When changing pages on a shop, it stops accepting controller and keyboard input until you use the mouse to hover
  over an item.
