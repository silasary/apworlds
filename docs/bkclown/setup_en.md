# BKCLOWN Multiworld Setup Guide

## Required Software

- Copy of Pizzeria Simulator.exe
- Windows (Sorry)
## Installation

    You may either run the client to make a folder named "BKCLOWN" in your archipelago folder, or create it yourself. Copy your version of FFPS.exe from your steam library into the "BKCLOWN" folder. Finally, open up the client and run "/patch", and it should create a new .exe called "BKCLOWN.exe". This process is currently only available for windows os, and may come to other os if I can write it to do so.

## Connecting

    Simply run the client and enter your archipelago ip in the top bar. If everything works, connecting and opening the game should send checks. (Suprising 0 Children is automatically sent as soon as you connect, sorry.)
