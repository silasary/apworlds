# Shard Lengths

As of Haste AP v0.5.0, Shopsanity and Fragmentsanity can be set to have Dynamic Scaling, which sets the amount of checks in each Shard relative to their **fixed** length of the Shards themselves. This page provides a table of each Shard and their respective lengths for both settings, as well as their expected check numbers for the default 80% quantity.

> The Shop Purchase count is currently determined by halving the fixed Fragment Length, rounded down. This number may be adjusted in future versions for balancing.
