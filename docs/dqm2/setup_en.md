# Dragon Quest Monsters 2 Setup Guide

## Required Software

- [Archipelago (0.6.7+)](https://github.com/ArchipelagoMW/Archipelago/releases)
- [Bizhawk](https://tasvideos.org/BizHawk/ReleaseHistory) 2.9.1 works for sure
- [DQM2 AP World](https://github.com/Whizzlefern/Archipelago/releases/latest)
- Your legally obtained Dragon Warrior Monsters 2 US ROM file (either version)

## Optional Software

- [Dragon Quest Monsters 2 Archipelago Map Tracker](https://github.com/OmegaZeron/DQM2-AP-PopTracker-Pack/releases/latest) for use with [PopTracker](https://github.com/black-sliver/PopTracker/releases/latest)

## Creating a YAML

1. Install the APWorld
2. Close any open Archipelago Launchers
3. Open the Archipelago Launcher
4. Open "Options Creator" and select "Dragon Quest Monsters 2" on the side
5. When done, click "Export Options"

### Note

Be sure to select the correct version you own and dumped using the `game_version` option in your settings.

## Important

You must be connected to the server to receive items.
