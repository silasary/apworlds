# Create Archipelago World

Create is a physics-based puzzle game about building contraptions. This Archipelago world targets the PAL Wii
SECP69 release and uses an external Dolphin client.

## Goals

- Goal World Unlock: earn the first Spark in Challenge 10 of the selected goal world
- Spark Hunt: collect the required number of Archipelago Sparks

## Locations

- Challenge Sparks
- Create Chains

## Items

- World unlocks
- Object unlocks
- AP-side Spark counter items (also displayed in the ingame pause menu)

## Options

- Spark Goal Mode:
  - Goal World Unlock
  - Spark Hunt

- Starting World, random or selected
- Goal World, random or selected
- Include II Worlds, default off:
  - Theme Park II
  - Family Home II
  - Outer Space II
  - Future World II

- Create Chain Checks, default on
- Required Sparks, 0-610, default 100

## Notes

This is an early release of the Create APWorld.

The Hub World Create Chain and its three parts are always included as locations. Create Chain Checks adds five checks per included world. AP-side Spark items are separate counter items used for goal world access or Spark Hunt. With Required Sparks set to 0, Spark Goal Mode is ignored: goal world access is a normal item, and earning the first Spark in its final challenge finishes the game.

The item pool adds up to 50% extra Sparks when space allows, with a maximum total of 610. Explicitly selecting a II world includes it even when Include II Worlds is off. Goal World is ignored in Spark Hunt with a positive Spark requirement.

Normal logic uses the intended object requirements. Universal Tracker can display known alternative solutions as glitched possibilities.
