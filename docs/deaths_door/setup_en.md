# Death's Door Randomizer Setup Guide

## Required software
- [Death's Door](https://store.steampowered.com/app/894020/Deaths_Door/)
- [BepInEx 5.4.22 or a later 5.x version](https://github.com/bepinex/bepinex/releases/latest)
- The Death's Door Archipelago mod and its dependencies, from the [latest release](https://github.com/Chris-Is-Awesome/DDArchipelagoRandomizer/releases/latest)
- [Archipelago 0.6.7 or later](https://github.com/ArchipelagoMW/Archipelago/releases/) with `deaths_door.apworld` from the same release

## Setup
Step-by-step instructions for installing the mod and the apworld, creating a yaml, generating and connecting are in the main README:
https://github.com/Chris-Is-Awesome/DDArchipelagoRandomizer#setup
