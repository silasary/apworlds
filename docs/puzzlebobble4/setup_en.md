# Puzzle Bobble 4 Setup Guide

## Requirements

- A legally obtained copy of *Puzzle Bobble 4* (NTSC-U/C, serial SLUS-00754).
- DuckStation version **0.1-12083-g00e299795 or later**.
- The Puzzle Bobble 4 Archipelago client executable (`.exe`).
- An Archipelago multiworld game session.

## Setup Instructions

1. **Launch DuckStation** and load *Puzzle Bobble 4*.
2. **Navigate to the Game Menu.** After the initial “Push Start Button” screen, proceed to the game's **Game Menu** before connecting the client.
3. **Launch the Puzzle Bobble 4 client** by running its `.exe` file.
4. **Wait for DuckStation to be detected.** The client should detect the running emulator automatically.
5. **Enter the Archipelago connection details:**
   - **Server Address:** Enter the server domain. Leave this field blank when connecting to `archipelago.gg`.
   - **Port:** Enter the port provided for your multiworld session.
   - **Slot Name:** Enter the slot name assigned to your player.
   - **Password:** Enter the server password if one is required. Leave this field blank if the session has no password.
6. **Connect.** Once the connection is established, the client is ready to communicate with your Archipelago game session.

You are now ready to play! Progress through Arcade Mode to send location checks to Archipelago and receive items from your multiworld session.
