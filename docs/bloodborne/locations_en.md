Tracker names retain the vanilla pickup as a recognizable handle. A parenthetical landmark tells you which physical spot the check replaces; numbered entries remain numbered so existing hints and spoilers stay stable.

Landmarks are added only after the item lot, acquisition flag, map placement, and a human-readable source can be joined. A bare or numbered name means the exact landmark is still unresolved, not that the pickup is missing.
