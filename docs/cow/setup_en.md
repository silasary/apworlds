# Setup

## Required software

* Archipelago 0.6.7
* Cow
* The [latest release of ArCowPelago](https://github.com/CodeTriangle/ArCowPelago/releases/latest)

## How to play

1. Install the apworld file to `custom_worlds` and create a YAML using the template from the releases page.
1. Generate and host the game.
1. Extract `Cow.zip` from the releases page into your Cow installation folder (so that `override.cfg` is on the same level as `Cow.exe`).
1. Enter the game normally. Click the gray Archipelago icon and enter your server details.
1. Select your DeathLink settings. **You are STRONGLY advised to choose a high amnesty value** (if you don't, you can change it at any time).
1. You must enter all levels through the Level Select screen.
