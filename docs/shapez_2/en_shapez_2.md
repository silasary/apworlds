# shapez 2

## What is this game?

shapez 2 is an automation game about cutting, rotating, stacking, and painting shapes, that you extract from
randomly generated islands in an infinite space, without having to pay for building your factories.
It is the successor to shapez and contains a variety of more features like crystals, space platforms and belts,
trains, and an astounding new 3-dimensional gameplay environment in space.

## What does randomization do to this game?

Buildings and gameplay mechanics, that you normally unlock by completing a milestone or buying an upgrade, are put into 
the item pool of the multiworld. Also, the shape requirements of milestones, tasks, and operator lines are randomized.

## What is the goal of shapez 2 in Archipelago?

As the game has no actual goal where the gameplay ends, there are (currently) 2 different goals you can choose from in 
the player options:
1. Milestones: Complete all milestones.
2. Operator levels: Check all operator level checks.
The amounts of milestones and operator level checks in your world can be adjusted in the player options.

## Which items can be in another player's world?

- Building unlocks
- Space platform unlocks
- Various mechanics (e.g. blueprints, additional floors, ...)
- Job line unlocks
- Operator line unlocks
- Platform capacity
- Research credits
- Bluprint credits

## What is considered a location?

- Milestones (3-20 milestones with 2-12 checks per milestone)
- Tasks (3-200 task lines with 1-5 checks per task line)
- Operator levels (0-200)

- ***How do I set up this game?***

      Discord server for more information.
  <br>Other than that, follow the [setup guide for this game.](setup_en.md)
- ***Where is the options page?***
  <br>As this game is not (yet) merged into main, type `&options` into the `#jenson-spam` channel on the 
      Discord server for more information.
- ***What about feature XY?***
  <br>This apworld uses custom scenarios, which are a feature already built into the vanilla game, and can thereby be 
      played without a mod. However, they are quite limited in how they can change the vanilla gameplay, so pretty much 
      every major feature that's not already implemented would inevitably require to use a mod.
- ***Is there a tracker?***
  <br>You can use the Universal Tracker, which is fully compatible with this game. See the 
      `#universal-tracker` channel on the Discord server for more information.
