# YOHANE THE PARHELION -BLAZE in the DEEPBLUE- Setup Guide

## Required Software

- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases)
- [YOHANE THE PARHELION -BLAZE in the DEEPBLUE- on Steam](https://store.steampowered.com/app/2404370/YOHANE_THE_PARHELION_BLAZE_in_the_DEEPBLUE/)

## Connecting to the Archipelago Server
Install the mod loader from https://github.com/SilicDev/YohaneBIDModLoader/releases/latest and the AP mod
from https://github.com/SilicDev/YohaneAPMod/releases/latest . Follow the setup instructions on both and configure your connection in
`.mods/YohaneAPMod/config.ini`. The game should automatically connect once you load into a save file.

### Old: Python client
With the game open, open the **YOHANE THE PARHELION -BLAZE in the DEEPBLUE- Client** from the Launcher and connect it to the Archipelago server.
